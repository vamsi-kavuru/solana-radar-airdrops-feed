Crypto Radar

Solana portfolio + airdrop tracker, built for mobile.

Crypto Radar is a privacy-first Android app that helps you watch your Solana wallets and never miss an airdrop. It's built for Solana Mobile devices (Saga, Seeker) and ships on the Solana dApp Store.

What it does

  • Airdrops, first-class. A continuously refreshed catalog of upcoming and live Solana airdrops. Filter by status, tap "Notify me" on any drop to get a local reminder when claims open.
  • Per-wallet eligibility. For Jupiter drops, Crypto Radar checks each connected wallet directly against Jupiter's worker and shows the allocation inline on each card.
  • Multi-wallet portfolio. Aggregate net worth across every wallet you watch — tokens plus native SOL, with logos and USD values.
  • Privacy-first. Every API call goes directly from your device. Crypto Radar runs no backend that touches your data — no account, no tracking, no analytics.

How to get it

Crypto Radar will be available on the Solana dApp Store for Saga and Seeker devices. Pre-release Android dev builds are available on request via the GitHub repo above.

Crypto Radar is built independently and is not affiliated with Jupiter, Solana Mobile, Solana Labs, or any protocol whose airdrops appear in the catalog.
